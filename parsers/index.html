    HCBench Parsers

    Use a parser to convert a caller's output into region-by-cell CNA matrices before benchmarking.

    Prepare caller output

    Parser Main Input Additional Inputs Format Types Supported Outputs
    CHISEL calls.tsv mapping.tsv, VAF table Tab-delimited text CNA Matrix, Clusters, Bin Counts, Sparse VAF
    Alleloscope .rds files clusters.csv, raw counts TSV, cellSNP directory R serialized data, TSV, CSV CNA Matrix, Clusters, Bin Counts, Sparse VAF
    CNRein CNReinPrediction.csv .npz arrays, split VCF files CSV, NPZ, VCF CNA Matrix, Bin RDR, Sparse VAF
    SEACON calls.tsv counts.tsv, vaf.tsv Tab-delimited text Split CNA Matrices, Bin Counts, Sparse VAF
    SIGNALS hscn.rds (exported to .tsv) cluster file, bin counts, VAF table Tab-delimited text / CSV CNA Matrix, Clusters, Bin Counts, Sparse VAF
    HCDSIM GT cell_cna_profile.csv — CSV CNA matrices, event annotation, event counts

    Choose the caller page above for its required columns and optional inputs. Create the output directory before parsing. Cluster, read-depth, and VAF files are generated by separate methods when the corresponding inputs are available.

    Initialize and parse

    bin_size and genome are required when creating a CNA parser, GTBench, or RealBench:

    • bin_size: a positive integer in base pairs, such as 100000 for 100 kb. It sets the event-analysis resolution and, when expand_bins=True, the maximum length of each output region.
    • genome: "hg19" or "hg38", matching your input coordinates.

    expand_bins=False is the default. Passing bin_size alone does not split CNA regions; initialization prints Expand bins: False (regions will not be split). Set expand_bins=True to split each input region into pieces no longer than bin_size before the CNA matrices are written. Initialization then prints Expand bins: True (regions will be split). The split pieces keep the input region's CNA values. bin_size is still used for event-analysis resolution when splitting is off.

    Methods use this configuration. Initialization prints:

    Bin size: 100000 bp
Genome: hg38
Expand bins: True (regions will be split)

    This example reads a CHISEL table containing #CHR, START, END, CELL, and HAP_CN:

    from pathlib import Path
from hcbench.parsers.chisel import ChiselParser

output = Path("results/CHISEL")
output.mkdir(parents=True, exist_ok=True)
parser = ChiselParser(
    input_path="chisel/calls/calls.tsv",
    output_path=str(output),
    bin_size=100000,
    genome="hg38",
    expand_bins=True,
)
parser.run()

    With expand_bins=True, the parser splits each input region into pieces of at most 100,000 bp before writing the matrices. run() writes haplotype_combined.csv, haplotype_1.csv, haplotype_2.csv, minor.csv, major.csv, and minor_major.csv for this example. Each CSV has a region column and one column per cell. SEACON writes only minor/major matrices by default; use output_haplotype=True for haplotype outputs. CHISEL can write separate clone and cell subdirectories when two value_cols are specified; see its caller page.

    Annotate CNA events

    After parsing, annotate the combined profile when you need event sizes and types:

    annotated = parser.annotate_segments(
    "results/CHISEL/haplotype_combined.csv",
    out_file="annotated_segments.csv",
    threshold=0.8,
    detect_cnv_type=True
)

    This writes results/CHISEL/annotated_segments.csv and returns the annotation DataFrame. Rows include cell, Chrom, Start, End, value, Segment, size, and type. The annotation defaults are threshold=0.8 and detect_cnv_type=True. Use chromosomes=["chr1", "chr2"] to select chromosomes; separate chromosome CSVs are also saved. With no selection, all input chromosomes are included.

    With the default event-size thresholds, analysis is available for:

    CNA bin_size Event categories
    <= 3,000,000 bp focal, medium, broad
    > 3,000,000 and <= 10,000,000 bp medium, broad
    > 10,000,000 bp broad

    Event length is End - Start + 1: focal is below 3 Mb, medium is from 3 Mb through 10 Mb, and broad is above 10 Mb. Whole-chromosome and whole-genome events are reported as broad. Categories unavailable at your resolution have no annotation or category-metric rows; a missing comparison is reported as NA rather than evidence of no events.

    For this method, small_size (default 3_000_000) and mid_size (default 10_000_000) set the event-size thresholds and corresponding resolution limits.

    Annotate ground truth

    For HCDSIM ground truth, prepare a CSV with chromosome coordinates and one column per cell. See HCDSIM GT for parsing, event annotation, event counts, and input requirements.

    Use the standardized matrices with GTBench when ground truth is available, or RealBench to compare callers.
